# Speak-Up Circuit

The Speak-Up petition circuit is Circom source for a Groth16 membership proof with a per-petition nullifier. This export contains the [circuit source](circuits/sign_petition.circom) with [pinned build inputs](SOURCE-PINS.json) and the [licensing scope](docs/LICENSING.md).

Obtain Circom 2.1.6 and circomlib 2.0.5 separately, then check them against SOURCE-PINS.json. The reviewed source build reproduced the expected WASM and R1CS. The full application, generated artifacts and setup records are held privately.

Read the accepted G4 definition candidate in the [Privacy Engine](https://github.com/sarobinson2011/privacy-engine) repository.
